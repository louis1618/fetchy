# Product

<!-- impeccable:product-schema 1 -->

## Platform

android

## Stack

Flutter UI and Kotlin native runtime; Room JSON records and SAF documents.

## Users

Mobile users saving media from URLs and Android shares to their own device.

## Product Purpose

Analyze a URL locally, choose real media and formats, download/merge/convert, and organize actual files.

## Capabilities and Constraints

Preserve downloads, background jobs, pause/resume/cancel/retry, cookies, settings, and old records. Support nested real folders, favorites, recent links and file previews. No Morit backend or source modifications. System share/location applications retain Android behavior.

## Brand Commitments

Fetchy. The five user-supplied October 2026 reference images are visual authority. White surfaces, blue selections, black pill actions, two-column media grid, colored folders, blue/pink oval mark. Sample content/counts are replaced by real records.

## Evidence on Hand

Reference images supplied in conversation; existing native tests and device logs under docs/test-results. Production data must never be fabricated to resemble sample thumbnails or metadata.

## Accessibility & Inclusion

System Back, safe areas, font scaling, explicit loading/error/empty states, and existing light/dark/system themes.
